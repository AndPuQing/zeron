# Zerun 0.3.2

Android now supports in-app release checks, verified downloads, and installation
through Android's system installer.

- Download `zerun-0.3.2-android.apk` for Android 10 or later, arm64 or x86_64.
- Check for updates from Settings or the sign-in screen. The app also checks on
  returning to the foreground after an hour since the last successful check.
- Downloads show progress and must match the release checksum, application ID,
  version, and pinned production signing certificate before installation.
- Completed downloads survive restarting the app. Cancelling installation lets
  you retry, and upgrading keeps your existing account data and settings.

Allow Zerun to install apps when Android asks, then return to confirm the update.
Version 0.3.0 has no in-app updater; install this signed APK once to enable future
updates. A Debug installation uses a different key and cannot be replaced in
place by a production release.

The desktop and CLI packages are included below with the same version.
