# Zerun 0.3.20

- Show cross-chat messages on iOS and Android with their sender and message
  body, keeping the source chat easy to recognize and open.
- Separate `/` commands from `$` skills on mobile, matching the desktop
  completion rules and preserving the selected skill's exact identity.
- Add provider and account switching, with sign-in actions from agent error
  cards on desktop and iOS. Android points to the computer where the agent
  needs to sign in.
- Run desktop sessions in a background engine and improve recovery after an
  interrupted engine or agent process, while preserving explicit user stops
  and the identity of imported sessions.
- Keep Claude logins working across CLI updates and update agent CLIs through
  the package manager or installer that owns them. DeepSeek Harness remains
  user-managed, with update notifications only.
- Add Muse Code support, including provider accounts, model discovery and
  session handling, and report startup failures without leaving a run stuck.
- Keep long transcripts connected by splitting large device RPC messages.
- Improve iPhone navigation and search, avoid an empty provider device picker,
  and preserve the open session when folding or unfolding an iPhone Duo.
- Preserve token usage and status feedback when agents compact their context.

Cloud hosting remains disabled in this self-hosted build.

Includes desktop packages for Linux, macOS, and Windows, plus the signed,
optimized ARM64 Android APK. The macOS app and disk image use Apple Developer
ID signing and notarization. Use the in-app update check or download the
matching package below.
