# Zerun 0.3.14

- Automatically choose between the direct service and the Hong Kong relay
  for desktop, iOS/iPadOS, and Android connections, with no configuration needed.
- Recover connections and update downloads through the alternate entrance
  when the selected route fails, while preserving existing login callbacks.
- Display native interactive visuals in Android chats, including controls,
  charts, canvases, 3D scenes, and shaders.
- Improve Android visual touch handling, accessibility, and animation lifecycle.
- Fix an Android startup failure caused by a missing native C++ runtime.

If Android 0.3.13 does not open, download the signed APK below and install it
over the existing app to preserve its data. The in-app updater cannot run
while the older app is unable to start.

Includes desktop packages for Linux, macOS, and Windows, plus the signed,
optimized ARM64 Android APK. The macOS app and disk image use Apple Developer
ID signing and notarization. Use the in-app update check or download the
matching package below.
