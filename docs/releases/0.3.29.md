# Zerun 0.3.29

- Improve provider updates, including managed OpenCode updates, updater-prompt
  detection, Muse version parsing and beta engine version tracking.
- Show side-chat activity in the parent session on mobile and keep delegated
  sessions distinct from side conversations.
- Improve citations and file references in agent replies, including structured
  sources and document reading on mobile.
- Make DSH model labels provider-specific and improve discovery of installed
  provider packages.
- Show complete command output from the owning host, with a redacted tail and
  exit status when output is shortened.
- Bind plugin consent to declared capabilities and restrict agent authority.
- Stop independent provider account probes and keep provider credentials within
  the configured execution environment.
- Refresh the app artwork and experimental desktop layouts and theme tooling.
- Recognize directory symlinks when browsing and searching projects.

Cloud hosting remains disabled in this self-hosted build.

Includes desktop packages for Linux, macOS, and Windows, plus the signed,
optimized ARM64 Android APK. The macOS app and disk image use Apple Developer
ID signing and notarization. Use the in-app update check or download the
matching package below.
