# Zerun 0.3.7

- Configure per-agent environment overrides on the execution device.
- Improve agent runtime stability, turn completion, stopping, and follow-up sends.
- Recover remote message delivery after suspension, restarts, and failed host wakes.
- Group finished subagents and show running counts in the sidebar and files panel.
- Open files from tool calls in the files panel or the system's default editor.

Includes desktop packages for Linux, macOS, and Windows, plus the signed,
optimized ARM64 Android APK. Use the in-app update check or download the
matching package below.
