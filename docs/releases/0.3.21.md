# Zerun 0.3.21

- Open terminals, subagents and side chats from the companion panels on iOS
  and Android, with a sidebar and inspector on tablets. Mobile terminals can
  use direct WebRTC links and fall back to the relay when needed.
- Refresh Android with agent account and provider controls, model selection,
  onboarding, voice controls and interactive visuals. Sessions now use a
  search bar, account avatar and a collapsible New session button.
- Tap Android transcript images to open a full-screen preview, with pinch
  zoom, panning and sharing.
- Preserve mobile side-chat drafts and attachments across navigation and
  window-size changes, and keep empty side chats until explicitly deleted.
- Discover preview servers started by an agent or app terminal and group
  them by chat, leaving unrelated local listeners out of the preview list.
- Browse prompt history from the desktop transcript rail, with one tick per
  prompt and a scrollable history for long conversations.
- Show cross-chat senders and provider switches above desktop messages, with
  a clickable sender that opens the source chat.
- Add Luau syntax highlighting and file recognition, and clear stale syntax
  highlights when files are reloaded after external changes.
- Show branch changes in the session card, close the card when switching
  chats, and keep fork-marker titles below popovers.
- Create desktop projects from a typed folder path with completion, remember
  each project's checkout choice, and choose whether pull requests open in
  the app or the default browser.
- Improve terminal rendering and remote input feedback, and correct Codex
  approval handling for the application's MCP tools.

Cloud hosting remains disabled in this self-hosted build.

Includes desktop packages for Linux, macOS, and Windows, plus the signed,
optimized ARM64 Android APK. The macOS app and disk image use Apple Developer
ID signing and notarization. Use the in-app update check or download the
matching package below.
