# Zerun 0.3.12

- Open pull requests in dedicated panes alongside sessions and the board.
- Select multiple files and folders for batch moves and deletion.
- Configure worktree folders separately for each device, with improved
  support for native Windows paths.
- Add overscroll bounce to the transcript, sidebar, and file tree.
- Show agent icons for idle side chats and subagent tabs.
- Prevent composer preferences from resetting during concurrent file access
  on Windows.
- Use `danger-full-access` as the default sandbox for dsh sessions.

Includes desktop packages for Linux, macOS, and Windows, plus the signed,
optimized ARM64 Android APK. The macOS app and disk image use Apple Developer
ID signing and notarization. Use the in-app update check or download the
matching package below.
