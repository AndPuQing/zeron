# Zerun 0.3.18

- Refine the iOS session import sheet with native controls, aligned filters,
  agent icons, selection checkboxes, and pull-to-refresh.
- Enable agent slash menus and local conversation actions on iOS and Android,
  including model selection, rename, copy, fork, and side chats.
- Order ACP reasoning levels from low to high and remove duplicate levels,
  fixing reversed effort sliders for newly advertised Grok models.

Includes desktop packages for Linux, macOS, and Windows, plus the signed,
optimized ARM64 Android APK. The macOS app and disk image use Apple Developer
ID signing and notarization. Use the in-app update check or download the
matching package below.
