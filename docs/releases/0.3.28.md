# Zerun 0.3.28

- Open Markdown and text file links from conversations inside iOS and Android.
  The read-only viewer includes Preview/Source modes, copy, document navigation
  and retry. Updated execution hosts transfer text in chunks and ask before
  reading files outside the conversation's workspace. These hosts also refuse
  protected credential locations.
- Install the standalone, signed Apple Silicon macOS CLI with the headless
  installer. Its user LaunchAgent keeps the engine running while logged in,
  and CLI updates remain separate from the desktop app.
- Show desktop update download progress in the sidebar.
- Reflect active side conversations in their parent session's activity
  indicator, and use consistent agent names across devices.
- Improve multiple-choice response cards and display Claude Code's server-side
  web tools in both main and subagent transcripts.
- Show Cursor usage buckets for the selected model, and keep Oh My Pi session
  discovery responsive with large histories.
- Reduce repeated Git probes and memory retained by streaming document
  snapshots.
- Add an optional experimental desktop with its own local profile and matching
  engine, including plugins, templates and registry agents. It is available
  through `scripts/experimental-desktop.sh`; the published packages keep the
  stable desktop. Experimental installers and automatic updates are not yet
  available.

Update the execution host and mobile app together for the complete document
viewer behavior. On older hosts, file contents may reach the phone before its
display confirmation, and transfer limits still apply. See the
[document viewer guide](https://github.com/AndPuQing/zeron/blob/v0.3.28/docs/mobile-document-preview.md)
for file, size and platform limits.

Cloud hosting remains disabled in this self-hosted build.

Includes Linux packages for x86_64 and ARM64, Apple Silicon macOS packages,
Windows x86_64 packages and the signed ARM64 Android APK. The macOS application,
disk image and standalone CLI use Apple Developer ID signing and notarization.
iOS is distributed separately through internal TestFlight. Use the in-app
update check or download the matching package below.
