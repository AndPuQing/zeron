# Zerun 0.3.22

- Use a single Companions panel on iOS for subagents, side chats and terminals,
  following the upstream phone and tablet navigation. Remove the duplicate
  side-chat panel, branch button and custom parent-title navigation.
- Open new side chats and forks through the same companion navigation, and
  use the normal session route for links back to a fork's source chat.
- Keep side-chat search, unsent drafts and attachments when navigating away;
  empty side chats remain available until explicitly deleted.

Cloud hosting remains disabled in this self-hosted build.

Includes desktop packages for Linux, macOS, and Windows, plus the signed,
optimized ARM64 Android APK. The macOS app and disk image use Apple Developer
ID signing and notarization. Use the in-app update check or download the
matching package below.
