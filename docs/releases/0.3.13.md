# Zerun 0.3.13

- Show native interactive visuals in desktop and iOS chats, including
  charts, tables, dashboards, canvases, 3D scenes, and shaders.
- Let agents publish visuals with the `show_visual` tool.
- Show or hide the Archived section in the desktop sidebar.
- Delete all archived sessions from Settings after confirmation.
- Improve file picker responsiveness and linked worktree detection.

Android displays a prompt to view interactive visuals on desktop or iOS.

Includes desktop packages for Linux, macOS, and Windows, plus the signed,
optimized ARM64 Android APK. The macOS app and disk image use Apple Developer
ID signing and notarization. Use the in-app update check or download the
matching package below.
