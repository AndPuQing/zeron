# Zerun 0.3.26

- Search message history on desktop, Android and iOS, then jump to matching
  messages in their conversations.
- Inspect and stop supported Claude Code and Codex background processes from
  desktop and phones, with protection against stale process responses.
- Show Claude Code's native next-prompt suggestions in the desktop composer.
  Accept a suggestion with Tab or Right arrow to edit it before sending;
  existing drafts take precedence. Requires a supported Claude Code version.
- Build Android session snapshots off the main thread to keep conversations
  responsive.
- Add fx as a native ACP provider, using its reported models, permission
  controls and session capabilities.
- Allow WebRTC direct links to fragment UDP packets over low-MTU networks,
  including Tailscale tunnels. Tailscale is not required.
- Serialize pending-message queue changes to prevent concurrent sends and
  queue draining from racing.

Cloud hosting remains disabled in this self-hosted build.

Includes desktop packages for Linux, macOS, and Windows, plus the signed,
optimized ARM64 Android APK. The macOS app and disk image use Apple Developer
ID signing and notarization. Use the in-app update check or download the
matching package below.
