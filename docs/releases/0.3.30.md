# Zerun 0.3.30

- Keep large cross-device chats responsive with bounded transcript reads and
  chunked RPC replies. Sending messages and follow-ups no longer waits for the
  entire chat history to load.
- Preserve attachments in queued messages and improve steering while commands
  or background tasks are running.
- Show running, waiting and background sessions in the iOS Activity view, with
  controls for sleeping and waking sessions.
- Preview PDF documents in the desktop Files panel.
- Keep long tool details accessible across refreshes and make startup timeout
  messages clearer for ACP agents.
- Reduce repeated repository inspections and keep process launches off runtime
  workers.
- Improve provider update ownership detection and keep desktop update downloads
  aligned with the selected Stable or Beta channel.

Cloud hosting remains disabled in this self-hosted build. Independent provider
quota queries and background account lookups remain disabled.

Includes desktop packages for Linux, macOS and Windows, plus the signed ARM64
Android APK. The macOS app and disk image use Apple Developer ID signing and
notarization. iOS is distributed separately through internal TestFlight.

The experimental desktop, including custom 3D plugin scenes, is distributed
through the separate [Desktop Beta channel](https://github.com/AndPuQing/zeron/blob/dev/docs/desktop-beta.md). Stable
installations keep their existing interface and update channel.
