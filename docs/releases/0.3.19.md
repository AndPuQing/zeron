# Zerun 0.3.19

- Match the iOS and Android `/` completion menus to the desktop command and
  skill rows, with the shared command and magic-wand icons, a single-line
  name and detail, and the same touch-size adaptations each platform needs.
- Keep same-name skills distinguishable: `$review` and `$review:2` render as
  `Review` and `Review · 2` while insertion still restores the exact command.
- Remove the outer ring from the Oh My Pi mark so the pi glyph stands on its
  own at menu sizes.

Includes desktop packages for Linux, macOS, and Windows, plus the signed,
optimized ARM64 Android APK. The macOS app and disk image use Apple Developer
ID signing and notarization. Use the in-app update check or download the
matching package below.
