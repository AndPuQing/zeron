# Zerun 0.3.27

- Open native agent configuration files from the desktop provider settings.
- Clarify provider permission controls and make Full Access easier to identify.
- Improve message search layout and feedback on Android and iOS.
- Add Settings → Usage on desktop, with local session and turn statistics,
  success and rework rates, agent time, task types and available plan limits.
- Add desktop selection actions to quote transcript text, code and diffs in
  the current conversation or ask about them in a side chat. Quotes remain
  editable before sending and preserve existing drafts.
- Show local images in settled assistant replies on Android and iOS. Persist
  embedded tool-result images so main and subagent transcripts can show them
  across devices, with bounded image reads, decoding and caches.
- Keep tool images when agents send image content separately from completion,
  and count early subagent image payloads toward the pending-event memory limit.
- Reuse existing workspaces when organization setup is retried.

Update the connected computer together with the mobile app to use the new
image previews. Previously discarded tool images cannot be recovered.

Cloud hosting remains disabled in this self-hosted build.

Includes desktop packages for Linux, macOS, and Windows, plus the signed,
optimized ARM64 Android APK. The macOS app and disk image use Apple Developer
ID signing and notarization. Use the in-app update check or download the
matching package below.
