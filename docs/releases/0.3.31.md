# Zerun 0.3.31

- Improve chat delivery, steering and Stop commands while an agent is busy.
- Enable negotiated chat relay for iOS and Android, with compatibility for
  older devices and clients.
- Improve drafts, notifications, session panels and provider account handling.
- Preserve matching engine versions during Cloud recovery and make recovery
  deadlines more reliable.
- Play macOS notification sounds through the system sound service and show
  identifiable microphone names on Windows.
- Repair platform builds and keep Windows native builds on a compatible Rust
  toolchain.

Cloud hosting remains disabled in this self-hosted build. Independent provider
quota queries and background account lookups remain disabled.

Includes desktop packages for Linux, macOS and Windows, plus the signed ARM64
Android APK. The macOS app and disk image use Apple Developer ID signing and
notarization. iOS is distributed separately through internal TestFlight.

The experimental desktop uses the separate
[Desktop Beta channel](https://github.com/AndPuQing/zeron/blob/dev/docs/desktop-beta.md).
Stable installations keep their existing interface and update channel.
