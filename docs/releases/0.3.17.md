# Zerun 0.3.17

- Import saved agent sessions from execution devices on iOS and Android,
  with agent filters and a dedicated **Not imported** view.
- Expand native history imports to GitHub Copilot, Cursor, Grok, Hermes,
  DeepSeek Harness, Pi, and OpenCode, alongside Codex and Claude Code.
- Add Oh My Pi (OMP) with native session creation and continuation, model
  and reasoning controls, steering, tool interactions, and saved-session imports.
- Adapt iOS navigation, transcript layout, and composer spacing to changing
  window sizes and uneven safe areas while preserving the open session.

Includes desktop packages for Linux, macOS, and Windows, plus the signed,
optimized ARM64 Android APK. The macOS app and disk image use Apple Developer
ID signing and notarization. Use the in-app update check or download the
matching package below.
