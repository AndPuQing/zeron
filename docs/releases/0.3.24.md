# Zerun 0.3.24

- Keep the configured 1M context window for custom Claude Code models,
  including discovered models and older cached catalogs.
- Keep Android's current agent models loading when provider tabs arrive,
  and preserve the other chat settings when selecting a different model.
- Show remote chat synchronization progress while a room catches up.
- Let agents show local images and Markdown images in replies, with images
  resolved within the chat's own workspace.
- Search settings from the desktop sidebar.
- Match keyboard shortcuts to non-US Mac keyboard layouts.
- Annotate browser elements and include them in chat prompts.
- Add a smooth mouse-wheel scrolling setting under Appearance.
- Add optional Linux WPE browser support. These release packages continue
  to use the existing WebKitGTK backend.

Cloud hosting remains disabled in this self-hosted build.

Includes desktop packages for Linux, macOS, and Windows, plus the signed,
optimized ARM64 Android APK. The macOS app and disk image use Apple Developer
ID signing and notarization. Use the in-app update check or download the
matching package below.
