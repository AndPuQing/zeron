# Zerun 0.3.11

- Add GitHub Copilot CLI as an agent option.
- Keep embedded browser login sessions, cookies, local storage, and IndexedDB
  across app restarts on Linux and macOS 14 or newer, with isolated profiles.
- Keep the Linux interface responsive while the embedded browser starts and
  report startup errors more clearly.
- Give new sessions without a project their own scratch folders, and improve
  workspace and home-directory search.
- Refine session grouping, account settings, and desktop navigation.
- Keep dsh capability discovery out of persistent conversation history.
- Sign and notarize the macOS app and disk image with Apple Developer ID.

Includes desktop packages for Linux, macOS, and Windows, plus the signed,
optimized ARM64 Android APK. Use the in-app update check or download the
matching package below.
