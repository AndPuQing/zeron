# Zerun 0.3.9

- Add DeepSeek Harness over ACP, with provider-grouped model selection and
  reasoning controls. Use the installed `acp-plus` profile when available;
  CLI installation and updates remain manual.
- Show running and imported session states in the importer. Handle interrupted
  Codex histories and stale Claude process registrations more reliably.
- Drag sessions into messages as references, reorder sidebar sections and
  queued prompts, and search desktop menus.
- Keep sidebar options visible when the sidebar is narrowed.

Includes desktop packages for Linux, macOS, and Windows, plus the signed,
optimized ARM64 Android APK. Use the in-app update check or download the
matching package below.
