# Zerun 0.3.15

- Add native Codex voice calls on Android, with live captions, mute,
  speaker controls, and a minimized call view.
- Keep Android calls accessible through a notification with mute and end
  controls, and release audio resources when a call ends or is interrupted.
- Align Android screens, navigation, and controls with the iOS design.
- Add Android session forks and side chat navigation.
- Show context compaction progress in chat on desktop, iOS/iPadOS, and Android.
- Fix account model defaults for Cursor Plus sessions and question forms
  in OpenCode sessions.

Includes desktop packages for Linux, macOS, and Windows, plus the signed,
optimized ARM64 Android APK. The macOS app and disk image use Apple Developer
ID signing and notarization. Use the in-app update check or download the
matching package below.
