# Zerun 0.3.25

- Choose permissions and Plan mode from desktop, Android and iOS. Mobile
  controls use the connected computer's supported modes and retain settings
  when changing models or restoring drafts.
- Keep permission and Plan restrictions when messages are queued, retried
  or delegated. Update the connected computer to use these controls from
  a phone; older hosts cannot accept restricted-mode messages.
- Support native agent permissions, Plan and staged approvals. Preserve
  existing OpenCode permission denials when applying access settings.
- Restore Codex Standard service when Fast is turned off.
- Render Markdown in user messages and session previews, fade folded
  messages, and keep long conversations scrolling smoothly.
- Let Zerun's Android updater coexist with the upstream app and verify
  that the installer can read the downloaded APK.
- Keep OpenCode launch configuration portable to Windows.

Cloud hosting remains disabled in this self-hosted build.

Includes desktop packages for Linux, macOS, and Windows, plus the signed,
optimized ARM64 Android APK. The macOS app and disk image use Apple Developer
ID signing and notarization. Use the in-app update check or download the
matching package below.
