# Zerun 0.3.6

- Switch sign-in and cloud sync to `https://edge.550w.host`.
- Use the new service for Linux installation downloads and Linux, macOS and
  Android update downloads.

Includes desktop packages for Linux, macOS and Windows, plus the signed,
optimized ARM64 Android APK.

Linux, macOS and Android users should download and install this release once
to switch from the previous service. Managed Windows installations can use
Check for updates.

The new service starts with fresh server storage. Data stored only on the
previous service was not transferred.
