# Zerun 0.3.23

- Show the sending chat title and provider above mobile message bubbles;
  tap the caption to open the source chat through the native navigation.
- Show outgoing chat messages with their recipients, open the receiving chat
  from its caption, and preserve run status while a message is in transit.
- Stream foreground Claude subagent text and thinking, including typed skill
  forks, with subagent chips and tabs that fit compact tool folds.
- Choose whether Claude uses native subagents in Settings → Providers.
  Turning them off delegates through side chats from the chat's next turn.
- Keep question answers visible after replying, and allow questions to be
  dismissed without an answer. Close copied pending questions and settle
  copied running subagent chips when forking a chat.
- Start chats from a device's No project group, and switch sessions by
  clicking rows in an open session card.
- Show image reads in chats, add tooltips and accessible names to icon
  buttons, and restore keyboard focus after leaving the macOS browser.

Cloud hosting remains disabled in this self-hosted build.

Includes desktop packages for Linux, macOS, and Windows, plus the signed,
optimized ARM64 Android APK. The macOS app and disk image use Apple Developer
ID signing and notarization. Use the in-app update check or download the
matching package below.
