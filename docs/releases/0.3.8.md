# Zerun 0.3.8

- Desktop: browse repository pull requests with filters, search, starred items,
  and cached results.
- Inspect descriptions, review activity, checks, images, and code diffs inside
  the app.
- Post comments from the detail view and keep drafts after failed submissions.
- Prepare review and fix prompts in a new agent session before sending them.

Includes desktop packages for Linux, macOS, and Windows, plus the signed,
optimized ARM64 Android APK. Use the in-app update check or download the
matching package below.
