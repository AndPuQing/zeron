# Zerun 0.3.32

- Stop a running turn and keep pending messages in the paused queue, with
  their attachments and permission settings preserved.
- Use Fast mode for supported models on iOS and Android. Mobile clients also
  show side-chat activity in the parent session and refresh model choices when
  the host reconnects.
- Use the chat relay on mobile when both ends support it. Reduce repeated
  writes while chat history syncs.
- Use Grok's Auto permission mode and see the reason when it asks for an
  approval. The Hermes model picker selects a default the signed-in provider
  can run.
- See clearer microphone names on Windows and hear notification chimes through
  the macOS system sound service.
- Fix history imports for dsh, the Muse installer on Linux, and updates between
  Linux Beta versions.

Download the package for Linux, macOS, or Windows, or the signed ARM64 APK for
Android. iOS builds are distributed through internal TestFlight.

The experimental desktop is available through the separate Beta channel.
[Desktop Beta setup](https://github.com/AndPuQing/zeron/blob/dev/docs/desktop-beta.md)
