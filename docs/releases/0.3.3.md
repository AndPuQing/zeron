# Zerun 0.3.3

The macOS, Windows, and Linux desktop apps now install as **Zerun** and can
coexist with Zeron.

- macOS installs `Zerun.app`; Windows installs Zerun with its own shortcuts
  and uninstall entry; Linux installs the `zerun` command and `zerun.service`.
- App data uses `~/.zerun` on macOS/Linux and `%LOCALAPPDATA%\Zerun` on Windows.
- Local communication and sign-in callback ports are separate. Use
  `ZERUN_DATA_DIR`, `ZERUN_IPC_PORT`, and `ZERUN_CALLBACK_PORT` for overrides.
- Desktop release packages and update payloads use the `zerun-` prefix.
  Install the matching package below; subsequent updates use Zerun's feed.

The signed Android APK is included with the same version.
