# Zerun 0.3.16

- Reorder sidebar groups by dragging them into place.
- Preview session details, side chats, and subagents from session info cards.
- Render LaTeX formulas natively on desktop and iOS, with font and size
  settings. Android keeps formulas readable as TeX source.
- Refine the session import dialog and keep its device picker above the dialog.
- Show pull request status and refresh stale activity while keeping loaded
  changes and comment drafts.
- Expand agent slash menus across desktop, iOS, and Android.

Includes desktop packages for Linux, macOS, and Windows, plus the signed,
optimized ARM64 Android APK. The macOS app and disk image use Apple Developer
ID signing and notarization. Use the in-app update check or download the
matching package below.
